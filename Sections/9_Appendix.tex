\section{Appendix}
\label{app:example}

The following steps prepare the template for a new manuscript:
\begin{enumerate}
  \item Select pdfLaTeX in Overleaf. Update the title, authors, affiliations, logos, and resource rows in \texttt{main.tex}.
  \item Edit the abstract and keywords in \texttt{Sections/1\_Abstract.tex}. Keep the abstract input before \verb|\maketitle|.
  \item Replace the section text and put illustrations in \texttt{Figures/}. Give figures, tables, equations, and sections unique labels.
  \item Add verified entries to \texttt{Reference.bib}. Use \verb|\citep{key}| for parenthetical citations or \verb|\citet{key}| for citations within a sentence.
  \item Recompile and check page breaks, figure placement, running headers, cross-references, and resource links.
\end{enumerate}

Keep mathematical notation consistent between equations and prose. Refer to each figure from the surrounding text, and use its caption to explain what readers should notice.
